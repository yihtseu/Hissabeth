# Optical model

## Sequential prescription

The sequential engine traces rays in double precision and supports spherical, conic, even-polynomial, and odd-polynomial profiles on internal surfaces and the object/image endpoints; toroidal profiles (a YZ conic section swept about an axis parallel to Y at the revolution radius, with even y⁴… coefficients; revolution zero gives a cylinder) and Zernike Fringe sag additions (Z1–Z37 in Fringe order, mm coefficients on a normalization radius, over any base) on internal surfaces; circular clipping apertures; per-surface intersections, normals, directions, refractive indices, and optical path lengths. Non-rotationally-symmetric profiles use Newton-refined two-dimensional intersections and Hessian-based normal derivatives; radial-only APIs (edge-thickness solves at a radial height, endpoint sags) reject them explicitly. Toroidal profiles take no radial asphere coefficients, and decentered Zernike sag is unsupported. Finite source points lie on the actual object profile, and rays intersect the actual image profile with signed propagation. Endpoint hit data includes normals and cumulative optical path length; endpoints do not refract. Analytic conic roots and damped polynomial intersections select the crossing nearest the vertex-plane intersection.

Finite and infinite object conjugates with a selectable object medium, two-axis fields, angle/object-height/image-height specifications, signed internal-stop pupil aiming, directional vignetting factors, and weighted wavelengths and fields. The model selects reference entrance-pupil mapping or per-ray real-stop aiming. Reference mapping holds the reference chief-ray offset and entrance plane across the spectrum; Geopter imports select it. Pupil specifications include entrance pupil diameter, f-number, object NA, and image NA. Sequential translations and optical path lengths retain their signs for negative gaps and virtual image planes.

All lengths are mm, wavelengths are nm, field angles are degrees, temperature is Celsius, and pressure is Pa. The last physical surface’s thickness places the image vertex. Image-height fields, Gaussian conjugates, autofocus, and marginal-height constraints retain their vertex-plane definitions. An infinite object requires a planar, unclipped source.

### Coordinate breaks and mirrors

An internal surface can carry an optional `transform`. Its lateral `decenter: [dx, dy]` is expressed in mm and its local Euler `tilt: [rx, ry, rz]` in degrees. The default applies decenter before tilt. Set `tilt_first` to reverse that order. By default the new frame continues through the following gaps and surfaces. Set `return_after` to restore the entering frame after the surface interaction, for example to perturb one tilted or decentered face. Dummy surfaces can carry persistent coordinate breaks without refraction. A tilted mirror and a downstream coordinate break can model a folded path.

ZMX `COORDBRK` imports as a plane dummy surface with a persistent transform. `PARM 1–2` encode decenter, `PARM 3–5` encode tilt, and `PARM 6` selects transform order. ZMX export writes persistent transforms on plane dummy surfaces. Use native JSON for transforms on refractive or reflective surfaces and for `return_after`.

Centered sequential mirrors retain the incident physical medium and reverse axial propagation. Real gaps are negative after an odd number of reflections and positive after an even number; the opposite sign represents virtual propagation. Type changes preserve all entered radii, gaps, and stored materials. The table displays the retained medium and propagation sign; layout arrows follow physical ray directions, including virtual extrapolations. First-order matrices use `q = direction_sign * physical_index * dy/dz`; `image_index` remains positive and `image_direction` reports the outgoing axial sign. EFL is the image-space focal length along outgoing propagation (positive for convergence), while BFL, image distance, and pupil positions retain global z signs. Finite-object afocal systems return valid conjugates with null focal lengths. Infinite-object afocal systems, including blank projects, return defined first-order quantities with null focal lengths, image conjugate, and working F-number; the metrics bar shows a dash for missing values. Autofocus and focus-dependent analyses require a finite focus.

The signed real/virtual gap convention follows [OpticStudio thickness definitions](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Thicknesses.html). [OpticStudio field-curvature documentation](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26102/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Field_Curvature_and_Distortion.html) describes parabasal Z focus shifts. The native curves use radial field-local axes and the stored image vertex, including curved images. These references describe the geometric conventions.

### Materials and AGF catalogs

Six embedded AGF catalogs containing 1,508 glasses, 13 dispersion formulas, Buchdahl model glass, custom AGF import, metadata search, environmental index evaluation, and catalog diagnostics. Missing thermal data and out-of-range wavelengths produce errors; incomplete transmission records are reported as warnings.

### Apertures, solves, and configurations

Separate physical clear radii and derived drawing semi-diameters. Every model update sizes internal surfaces and endpoints from the reference-wavelength chief and four field-local pupil rim rays across all saved fields, ignoring physical clipping. Coverage reports retain reached prefixes and identify object, internal-surface, and image failures. The object envelope measures field-point extent; the image envelope measures actual sampled intersections. Image apertures can limit automatic vignetting. This five-ray envelope estimates the drawing size from those samples. Automatic vignetting searches four global pupil directions, stores finite factors below 1 (including negative expansion), and resolves gap constraints together. A blocked chief, geometry-limited boundary, or failed convergence rejects the operation; stored directional rim rays must transmit before success. With no physical clipping apertures, Auto resets all factors to zero.

Persistent pickup, edge-thickness, overall-length, and marginal-ray-height gap solves, stored on each surface. Fixed gaps can be edited directly. Model edits, imports, recovery, and autofocus recalculate the relations atomically. Affine equations are solved jointly; damped Newton steps handle ray constraints and autofocus feedback. Singular, inconsistent, and nonconvergent constraints reject the operation. Removing a relation retains its last resolved thickness.

Edge-thickness targets are signed global axial edge separations; final-gap edge thickness includes the image profile sag. Overall length sums signed gaps as net axial displacement. A zero marginal zone selects the full-aperture paraxial axial ray. Nonzero zones trace the first prescribed field at the reference wavelength; ±1 is the nominal pupil rim, and overfilled zones are accepted when the ray geometry and apertures allow them. Autofocus requires a freely editable final gap and resolves its focus condition together with all other gap relations.

Multi-configuration tables store up to 64 named configurations whose operands override shared base values: surface thickness, radius, conic, aperture, material, and the object distance. The saved document keeps one active index; every analysis tool, layout, spot, fan, diffraction, and report evaluates the resolved prescription with that configuration's overrides applied, while `system_get` and project exports retain the full authoring table. `system_resolved` exposes the evaluated copy and `configuration_activate` switches the active index atomically. Autofocus evaluates the resolved prescription and writes the focused thickness back into the active configuration's thickness operand when one exists, otherwise into the shared base gap; automatic vignetting evaluates the resolved prescription and stores shared field factors. Thickness operands require fixed gap solves, duplicate operands per surface are rejected, and the prescription report's general section lists the table and every override. The Configurations view edits the table and the active selection on the shared draft.

## Analysis and inspection

First-order reduced-angle matrices, focal lengths, conjugates, and pupil locations with distinct object/image indices; object-medium-aware launch, Snell refraction, and signed optical path lengths; paraxial object/image NA and working f-number; autofocus; area-weighted grid and hexapolar monochromatic/polychromatic spots; monochromatic and weighted polychromatic geometric MTF; ray and OPD fans; chromatic focus; longitudinal aberration and spherochromatism; analytic sagittal/tangential chief-ray focus; distortion; geometric encircled energy; reference-sphere wavefront maps; FFT PSF and monochromatic/polychromatic diffraction MTF; direct Huygens–Fresnel PSF/MTF cross-validated against the FFT path; Noll Zernike wavefront decomposition; paraxial Gaussian-beam q-parameter propagation and Gaussian-overlap fiber coupling. Both MTF methods sum complex OTFs on common physical frequencies, retaining lateral color and sampled aperture transmission. Weighted analyses skip zero-weight wavelengths. Spherochromatism displays every stored wavelength, including duplicates and zero weights, against one reference focus, with per-wavelength clipped-ray diagnostics. Diffraction components retain their own physical pixel pitch and contribute zero above their cutoff; a failed positive-weight reference PSF rejects the analysis. Ray/OPD fans, chief-ray focus, and diffraction MTF use field-local tangential/sagittal axes; geometric MTF uses global x/y axes. Distortion reports signed radial error against the paraxial chief-ray intercept at the stored image plane, including finite conjugates.

Ray inspection presents per-surface axial and selected-field chief paraxial tables, normalized-pupil real rays, and explicit finite-source XY / direction-slope launches. Paraxial rows report global two-axis height, incoming/outgoing slope, signed reduced angle and index; internal/image rows use vertex planes, the finite chief starts at the actual source profile, and the axial ray starts at its vertex. Conic terms, higher polynomials, physical clipping and vignetting do not affect these linearized tables. Real pupil inspection uses saved pupil mapping and field vignetting; source launches start on the actual profile with unit `(dx/dz, dy/dz, 1)` and bypass pupil aiming. Real tables include launch, internal interactions, image, normals, physical indices and signed OPL. Physical failures retain the traced prefix and attempted hit without inventing interaction data. Runs are submitted manually against the saved revision; input edits, changed revisions and offline transitions discard results and late replies. Empty numeric inputs block submission.

Continuous field-curvature curves cover every stored wavelength, including duplicates and zero weights, with sagittal/tangential shifts referenced to one global image vertex. The default scan runs from zero to the largest saved field radius along +Y; axis directions and stored two-axis field endpoints select other slices. Analytic infinitesimal bundles differentiate real intersections, implicit conic-plus-polynomial normals, Snell refraction and reflection, and are shared with single-field astigmatism. Finite bundles originate on the actual source profile; infinite bundles are plane waves. Signed focal coordinates support centered mirrors and virtual conjugates. Only chief-ray apertures are checked. Each focus branch retains its own failure, including infinity; failed samples break curves. The view provides all-wavelength colors, 2–257 field samples, manual horizontal ranges, capped failure details and revision-aware restart recovery.

The Prescription report view assembles selectable general information, optical specification, first-order data, lens data, and every object/internal/image profile. Structured cells and the text download share one backend representation; numeric cells retain full precision while display decimals range from 0 to 15. Reports include principal planes, signed focal/pupil positions, two-axis optical invariants, Gaussian conjugates, actual media, material dispersion, gap relations, and all saved coefficients, colors, duplicate entries and zero weights. Inapplicable quantities are distinct from localized calculation errors. Generation is manual and read-only; changing inputs, saved revision or connection clears the result and download. An empty section selection produces the header only.

Diffraction uses scalar Fraunhofer propagation with a paraxial exit-pupil mapping; PSF intensity sums to one. The Huygens PSF/MTF evaluate the same model by direct pupil summation at arbitrary image sampling, independently of the FFT lattice. Gaussian-beam and fiber-coupling tools are unclipped, unaberrated paraxial q-parameter calculations with a flat-phase fiber mode at the stored image plane. With a curved image, PSF/MTF sampling remains a planar lateral grid centered on the actual chief intercept. Layout rays use the reference wavelength independently of the spot wavelength selection.

## DLS optimization

`optimize` runs native damped least squares (Levenberg–Marquardt) on the sequential prescription. Choose up to 64 variables and 256 weighted merit operands. Variables include radius, gap thickness, conic and asphere coefficients, model-glass parameters, decenter and tilt, and configuration overrides. Merit operands include RMS spot, wavefront, EFL, BFL, f-number, track, center and edge thickness, distortion, color, chief-ray angle, and ray intercept.

A preview evaluates the candidate prescription without saving. To commit the result, call `optimize` with `apply: true` and the current workspace revision. The engine saves the optimized prescription atomically. `design_summary` provides first-order metrics, per-field polychromatic RMS spot, distortion, axial color, and minimum center and edge thickness for quick inspection.

## Tolerancing

`tolerance_sensitivity` evaluates plus and minus perturbations and ranks their impact on the selected optical criterion, with a root-sum-square estimate. Supported perturbations include radius, thickness, surface and element decenter and tilt, refractive index, and Abbe number. An optional autofocus compensator measures the effect of refocusing.

`tolerance_monte_carlo` runs parallel seeded trials with normal or uniform perturbations and the same optional compensator. It reports distribution statistics and percentiles, a histogram, compensator stroke range, and yield against the supplied pass threshold. Both tools evaluate the saved prescription without committing the tolerance trials.

### Polarization and Gaussian beam size

A source can set `polarization` to `unpolarized`, `horizontal`, `vertical`, `diagonal45`, `right_circular`, `left_circular`, or `linear` with `angle_deg`, encoded as an object with a `kind` field. Polarized segments return normalized `jones` components in the beam's horizontal and vertical basis, each as `[real, imaginary]`. On a flat bench these correspond to p and s. Waveplates apply `retardance_waves` and `fast_axis_deg` (defaults 0.5 and 0°). Linear polarizers use the same axis field and, like PBS cubes, default to an extinction ratio of 1000. PBS branches share all incident power. Waveplates and polarizers apply their stored transmittance. Fresnel stacks and lens-group ghosts retain polarization-averaged power coefficients. Curved mirrors reflect with a paraxial slope correction from the signed `focal_length`.

A source can also set `waist` (1/e² intensity radius), `waist_offset` (positive downstream), and `m2`. The Gaussian report follows specular center rays and propagates the paraxial q parameter through free space, thin focusing optics, and real lens-group matrices. It reports radii at segment endpoints and compares clear aperture diameter with beam radius ω. A clear diameter of at least 3ω is `ok`, 2ω to 3ω is `tight`, and below 2ω is `clipped`. This is an aperture-clearance estimate. The geometric power ledger continues to use traced ray packets.

## Project exchange

Native JSON retains the full prescription, including solve definitions, coordinate transforms, configurations, embedded catalogs, and the bench.

### ZMX sequential files

ZMX (Zemax OpticStudio sequential) import and export cover UNIT MM files with STANDARD, EVENASPH, ODDASPHE, TOROIDAL (PARM1 revolution radius, PARM 3–8 y⁴…y¹⁴ coefficients), ZERNFRIN (PARM13 term count, PARM14 normalization radius, PARM 15–51 Fringe Z1–Z37 coefficients) profiles, plane dummy COORDBRK surfaces, circular CLAP clear apertures, catalog glasses resolved through GCAT against the embedded AGF library, MODEL glasses (mapped to the Buchdahl `nd:vd` form), MIRROR surfaces, angle and object/image-height fields, ENPD/F-number/object-NA pupils, WAVM/WAVL wavelengths, symmetric VCX/VCY vignetting, TEM/PRES, STOP, COMM labels, and RAIM pupil-aiming selection. Multi-configuration files map between the native table and the trailing CONF/MNUM section: THIC, CRVT, CONI, SDIA (clear semi-diameter), and GLSS operands become thickness, radius, conic, aperture, and material overrides, configuration-one values equal to the stored base are absorbed into the SURF blocks, and XFIE/YFIE/WAVE rows must match the shared fields and wavelengths. EVENASPH r², ODDASPHE r¹/r², and TOROIDAL y² terms, decentered Zernike sag, telecentric or afocal flags, obscured or decentered apertures, non-sequential content, endpoint and MIRROR operands, model-glass GLSS operands, and every other operand code are rejected with explicit errors. Export refuses benches, dummy surfaces without transforms, gap solves, custom catalogs, image-space NA pupils, asymmetric vignetting, FUSED_SILICA media, and surfaces combining toroidal with Zernike sag or asphere coefficients with Zernike sag; field/wavelength colors and semi-diameter solves are not stored in the format.

### Geopter JSON

Geopter export requires a finite object gap, refractive interactions, 25 °C, 101325 Pa, and reference entrance-pupil mapping. Use native JSON for embedded catalogs, gap solves, coordinate transforms, multiple configurations, or benches. Geopter profiles store ten polynomial coefficients: export writes all ten entries and rejects longer lists or mixed even/odd lists on any profile. Nonzero gap or material data following the terminal image is rejected on import. The built-in `FUSED_SILICA` dispersion model requires native JSON.
