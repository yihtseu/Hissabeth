# Hissabeth

A CPU optical design workbench built with Rust, Tauri, and Vue. The desktop editor and agents share one optical prescription through an MCP stdio relay and an authenticated loopback broker.

**The Geopter port is in progress.** The editor and MCP cover the current sequential core; full Geopter behavior and numerical coverage remain incomplete. GPU acceleration is outside the project scope.

## Optical model and editor

- Centered sequential f64 ray tracing with spherical, conic, even-polynomial, and odd-polynomial profiles on internal surfaces and the object/image endpoints; circular clipping apertures; per-surface intersections, normals, directions, refractive indices, and optical path lengths. Finite source points lie on the actual object profile, and rays intersect the actual image profile with signed propagation. Endpoint hit data includes normals and cumulative optical path length; endpoints do not refract. Analytic conic roots and damped polynomial intersections select the crossing nearest the vertex-plane intersection.
- Centered sequential mirrors retain the incident physical medium and reverse axial propagation. Real gaps are negative after an odd number of reflections and positive after an even number; the opposite sign represents virtual propagation. Type changes preserve all entered radii, gaps, and stored materials. The table displays the retained medium and propagation sign; layout arrows follow physical ray directions, including virtual extrapolations. First-order matrices use `q = direction_sign * physical_index * dy/dz`; `image_index` remains positive and `image_direction` reports the outgoing axial sign. EFL is the image-space focal length along outgoing propagation (positive for convergence), while BFL, image distance, and pupil positions retain global z signs. Finite-object afocal systems return valid conjugates with null focal lengths. Infinite-object afocal systems have no finite image conjugate.
- Finite and infinite object conjugates with a selectable object medium, two-axis fields, angle/object-height/image-height specifications, signed internal-stop pupil aiming, directional vignetting factors, and weighted wavelengths and fields. The model selects reference entrance-pupil mapping or per-ray real-stop aiming. Reference mapping holds the reference chief-ray offset and entrance plane across the spectrum; Geopter imports select it. Pupil specifications include entrance pupil diameter, f-number, object NA, and image NA. Sequential translations and optical path lengths retain their signs for negative gaps and virtual image planes.
- Six embedded AGF catalogs containing 1,508 glasses, 13 dispersion formulas, Buchdahl model glass, custom AGF import, metadata search, environmental index evaluation, and catalog diagnostics. Missing thermal data and out-of-range wavelengths produce errors; incomplete transmission records are reported as warnings.
- First-order reduced-angle matrices, focal lengths, conjugates, and pupil locations with distinct object/image indices; object-medium-aware launch, Snell refraction, and signed optical path lengths; paraxial object/image NA and working f-number; autofocus; area-weighted grid and hexapolar monochromatic/polychromatic spots; monochromatic and weighted polychromatic geometric MTF; ray and OPD fans; chromatic focus; longitudinal aberration and spherochromatism; differential sagittal/tangential focus; distortion; geometric encircled energy; reference-sphere wavefront maps; FFT PSF and monochromatic/polychromatic diffraction MTF. Both MTF methods sum complex OTFs on common physical frequencies, retaining lateral color and sampled aperture transmission. Weighted analyses skip zero-weight wavelengths. Spherochromatism displays every stored wavelength, including duplicates and zero weights, against one reference focus, with per-wavelength clipped-ray diagnostics. Diffraction components retain their own physical pixel pitch and contribute zero above their cutoff; a failed positive-weight reference PSF rejects the analysis. Ray/OPD fans, differential focus, and diffraction MTF use field-local tangential/sagittal axes; geometric MTF uses global x/y axes. Distortion reports signed radial error against the paraxial chief-ray intercept at the stored image plane, including finite conjugates.
- Separate physical clear radii and derived drawing semi-diameters. Every model update sizes internal surfaces and endpoints from the reference-wavelength chief and four field-local pupil rim rays across all saved fields, ignoring physical clipping. Coverage reports retain reached prefixes and identify object, internal-surface, and image failures. The object envelope measures field-point extent; the image envelope measures actual sampled intersections. Image apertures can limit automatic vignetting. This five-ray envelope is a sampled drawing size, not a continuous-pupil bound. Automatic vignetting searches four global pupil directions, stores finite factors below 1 (including negative expansion), and resolves gap constraints together. A blocked chief, geometry-limited boundary, or failed convergence rejects the operation; stored directional rim rays must transmit before success. With no physical clipping apertures, Auto resets all factors to zero.
- Persistent pickup, edge-thickness, overall-length, and marginal-ray-height gap solves, stored on each surface. Fixed gaps remain freely editable. Model edits, imports, recovery, and autofocus recalculate the relations atomically. Affine equations are solved jointly; damped Newton steps handle ray constraints and autofocus feedback. Singular, inconsistent, and nonconvergent constraints reject the operation. Removing a relation retains its last resolved thickness.
- Edge-thickness targets are signed global axial edge separations; final-gap edge thickness includes the image profile sag. Overall length sums signed gaps as net axial displacement. A zero marginal zone selects the full-aperture paraxial axial ray. Nonzero zones trace the first prescribed field at the reference wavelength; ±1 is the nominal pupil rim, and overfilled zones are accepted when the ray geometry and apertures allow them. Autofocus requires a freely editable final gap and resolves its focus condition together with all other gap relations.
- Editable prescription/specification tables, object medium and endpoint labels, field/wavelength RGB controls, material search and diagnostics, native prescription JSON and Geopter project text import/export, plots, pupil masks, saved-solve editing/removal/recalculation, read-only controlled thicknesses, and reference-preserving surface deletion. Staged object/image profile controls share Apply and Revert; the layout can include the finite object at its true distance. JSON object-key order does not create a draft change or reset a saved solve form. Stale views block writes. Confirmed writes remain successful if a following refresh fails; polling recovers the view without repeating the write or overwriting newer local edits. Analysis replies carry the actual engine revision; superseded requests and engine-ahead results are discarded. Sampling/spectral controls survive saved-system refreshes, and the spot canvas draws every returned point. Native and Geopter exchange retain endpoint labels, the object medium, and field/wavelength RGBA values. Duplicate wavelength and field entries keep their own plot colors; RGB editing preserves alpha and leaves untouched decimal values intact. Plot colors use saved RGB independently of alpha, following Geopter rendering.

The signed real/virtual gap convention follows [OpticStudio thickness definitions](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Thicknesses.html). This is a convention reference, not an OpticStudio numerical comparison.

All lengths are mm, wavelengths are nm, field angles are degrees, temperature is Celsius, and pressure is Pa. The last physical surface's thickness places the image vertex. Image-height fields, Gaussian conjugates, autofocus, and marginal-height constraints retain their vertex-plane definitions. An infinite object requires a planar, unclipped source. Diffraction uses scalar Fraunhofer propagation with a paraxial exit-pupil mapping; PSF intensity sums to one. With a curved image, PSF/MTF sampling remains a planar lateral grid centered on the actual chief intercept, not integrated detector irradiance. Layout rays use the reference wavelength independently of the spot wavelength selection.

Centered axial reflection is implemented. Tilted/decentered coordinate frames, polarization/coatings, optimization, tolerancing, and nonsequential propagation remain unfinished. Geopter export requires a finite object gap, refractive interactions, 25 C, standard pressure, no embedded custom catalogs, and no active gap relations, and reference entrance-pupil mapping. Geopter profiles store ten polynomial coefficients: export writes all ten entries and rejects longer lists or mixed even/odd lists on any profile. Nonzero gap or material data following the terminal image is rejected on import. The built-in `FUSED_SILICA` dispersion model requires native JSON. Native JSON retains the full current prescription, including solve definitions.

## Run and agent access

```sh
bun install
bun run tauri dev
```

Keep the desktop app open while using an agent. Startup detects Codex and Claude Code on PATH and invokes their MCP registration commands. The connection panel can repeat registration and show its result. Restart an agent after changing its registration.

Example agent request: “Read the prescription, design a BK7 singlet with a 50 mm focal length, focus it, and report the RMS spot radius.” Read `system_get` before editing: every mutating tool requires its current revision. MCP exposes 34 tools covering prescriptions, materials, tracing, analyses, solves, and project exchange. The `capabilities` tool returns the full tool schemas and current scope.

The application stores the prescription and endpoint descriptor under `$XDG_DATA_HOME/hissabeth` (default `~/.local/share/hissabeth`) on Unix and `%LOCALAPPDATA%/hissabeth` on Windows. `HISSABETH_DATA_DIR` selects a workspace; the desktop and agents must select the same one. The broker binds to loopback and authenticates with an OS-generated 256-bit token. Workspace leases prevent concurrent writers; atomic saves and revision checks protect edits. The relay rereads the endpoint for each request so an existing relay can reconnect after an engine restart.

Tool results contain one JSON document in MCP text content, including array results. The relay reads complete outbound replies; the maximum tested colored-spot reply was 65,620,434 bytes. Incoming request limits and socket timeouts still apply.

The executable also provides `--engine` for the headless broker, `--mcp` for stdio, `--detect-agents`, and `--configure-agents`.

```sh
cargo build --manifest-path src-tauri/Cargo.toml --no-default-features
src-tauri/target/debug/hissabeth --engine
```

Production desktop builds embed the existing `dist` output:

```sh
bun run build
cargo build --manifest-path src-tauri/Cargo.toml --features tauri/custom-protocol
```

Build artifacts belong in the existing `dist` and `src-tauri/target` directories.

Tilted reflection requires coordinate frames beyond the upstream reflection stubs; startup recovery for invalid externally edited files is also unfinished. The new local analyses and finite-conjugate reference have analytic and invariance tests; they have not been numerically compared with OpticStudio. The advertised FFT and wavefront grid constraints now match the runtime validators. The audit’s FFT endpoint recommendation requires numerical assessment before implementation; it is not a demonstrated defect. Agent registration tests used isolated executable fixtures and did not change personal CLI settings.

The upstream Buchdahl model-glass coefficient denominator uses a minus sign that fails to reproduce its specified Abbe number. Rust retains the algebraically correct plus sign and the existing Abbe-number identity test. The Sasian model-glass comparison therefore isolates the reference wavelength; the independent catalog-glass triplet exercises the full three-wavelength spectrum without that upstream defect. Earlier first-order/chief evidence does not establish off-reference model-glass agreement.

Spot, encircled-energy, geometric-MTF, wavefront, and FFT analyses sample the full nominal pupil with physical-aperture clipping, independent of stored ray-coordinate compression factors. Layout/reference rays, ray fans, and differential focus retain those coordinate factors. These sampled fractions do not provide absolute radiometric throughput or relative illumination. High-density replies still occupy memory proportional to the returned points, and a canvas frame draws synchronously. Exact f64 JSON parsing preserves values across edits and recovery. Huygens propagation, through-focus/field-matrix MTF, Zernike decomposition, complete project representation, and broader OpticStudio numerical comparisons remain unfinished. No remote repository is configured, so private/public synchronization has not run.
